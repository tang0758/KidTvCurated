## 1. 版本概述与发版产物

小剧场 2.0 带来了架构级的越级升级：
- **互动学习角 2.0**：卡片数据与多媒体从 APK 解耦，支持点读（不扣时长账本）、加权降频轮播、LWW 掌握度同步。
- **媒体内核越级**：零体积软解回退（拯救 4xxx 崩溃）、ExoPlayer 切集无缝复用、跳过片头片尾、慢放倍速与画面比例调节。
- **双模媒体网关**：原生 HTTP 206 Partial Content 流媒体加速（优先） + SMB（透明兜底）。
- **极简运维体验**：内嵌 8899 端口扫码免遥控配网、长按快捷重置/打卡、1080p 密度锁定。

### 📦 安装包路径

| **正式 Release 包** | `dist/KidTvCurated-v2.0-release.apk` 或 根目录 `小剧场.apk` | 生产包（24.9 MB，已签名，适合日常使用） |

## 2. 电视端安装与免遥控配网

### 2.1 安装方式

#### 方式 A：U 盘直接侧载安装（推荐家庭使用）
1. 将 `dist/KidTvCurated-v2.0-release.apk` 复制到 U 盘根目录。
2. 插入电视 USB 口，打开电视自带的「文件管理器」或「应用安装器」，点击安装即可。

#### 方式 B：局域网 ADB 命令行快速安装
电视开启 ADB 调试（通常在设置 -> 系统信息 -> 连击版本号开启开发者选项）：
```bash
# 连接电视（假设电视 IP 为 192.168.31.200）
adb connect 192.168.31.200:5555

# 覆盖安装 v2.0
adb install -r dist/KidTvCurated-v2.0-release.apk
```

---

### 2.2 免遥控扫码配网（OPT-29）
首次打开应用或需要更换 NAS 地址时，**无需拿着遥控器吃力打字**：
1. 启动小剧场应用，电视会在后台启动轻量配网服务（端口 `8899`）。
2. 在同一 WiFi 下的手机或电脑浏览器中直接打开配网页面：
   ```text
   http://<电视IP>:8899/pair
   ```
   *(电视屏幕或控制台日志中均可查看电视本地 IP)*
3. 网页会展现简洁的配网表单：
   - **NAS IP / 主机名**：例如 `192.168.31.72`
   - **端口**：默认 `445`
   - **用户名 / 密码**：NAS 的访问账号
   - **媒体共享名**：例如 `儿童资源` 或 `data`
4. 点击 **「保存到电视」**，电视端将在 `<1s` 内收到热推送并立即刷新片单与规则。

## 3. NAS 侧资源完整部署指南

电视端采用「约定大于配置」的规范工作区，建议在 NAS 共享目录下统一收口到 `curated/`。

### 3.1 推荐目录层级结构
```text
\\<NAS-IP>\data\ (或你放置视频的主共享目录)
 └── curated\
      ├── tv.json                  # 【核心】主片单与时段规则配置文件
      ├── learning.json            # 【新增】互动学习角 2.0 卡片库配置
      ├── state.json               # 【自动生成】观看进度、打卡天数与掌握度双向备份
      ├── control.json             # 【可选】家长手机远程锁定/加时控制卡
      ├── logs\                    # 【自动生成】电视运行异常诊断日志归档
      └── learning\                # 【新增】多媒体素材文件夹
           ├── images\             # 卡片配图 (.jpg / .png，例如 poem_chun_xiao.jpg)
           └── audio\              # 点读音频 (.mp3，例如 poem_chun_xiao.mp3)
```

### 3.2 准备 `learning.json` 卡片库
项目已提供一键导出工具，将内置的 255 张卡片（57 首唐诗、78 个英语单词、70 个识字成语、50 幅世界名画）一键导出：

### 3.3 准备点读音频与配图（渐进增强）
- **多媒体文件为可选加载**：
  - 如果配置了配图，电视端自适应展现 **左侧配图 38% + 右侧文字 62%** 双栏；若无图，自动 100% 居中大字显示，绝不白屏或裂图。
  - 如果配置了点读音频，孩子按遥控器 `OK` 键即可朗读，且**完全不计入看片时长限额**；若无音频，按 `OK` 键顺畅翻到下一张。
- **推荐点读语音生成**：
  可使用 `edge-tts` 批量根据 `ttsText` 生成高品质自然女声/童声（中文 `zh-CN-XiaoxiaoNeural`，英文 `en-US-JennyNeural`）。

## 4. 双模流媒体网关部署 (HTTP 206 加速)

为了彻底解决 Android TV 跑 SMB 协议容易单线程锁死、高码率卡顿的问题，2.0 提供了轻量 HTTP 流媒体网关服务。

### 4.1 启动管理控制台与媒体网关
在 NAS（支持 Docker/Python 环境）或常开的家庭微主机/PC 上运行：
```bash
python3 tools/console.py
```
控制台将监听在 `http://<IP>:8765`：
- **Web 管理界面**：提供片单可视化编排、学习卡片与掌握度专页、远程遥控。
- **HTTP 206 Partial Content 网关**：支持范围分片下载，路由为 `/stream/<share>/<path>`。

### 4.2 双模降级机制
电视端在启动与切集时会向 `http://<NAS-IP>:8765/api/desktop/ping` 发起瞬时探活：
- **网关在线**：电视优先走高吞吐 HTTP 流媒体通道（秒开拖拽）。
- **网关离线 / PC 关机**：电视无感、透明自动降级为原生 SMB 协议播放，确保全天候高可用。

## 5. 自动化测试与代码校验

在提交或部署新构建前，必须确保以下三道质量守卫 100% 绿灯：

```bash
# 1. 运行 Android 单元测试（包含加权抽样、状态合并、时段解析等 52 项任务）
./gradlew test

# 2. 运行界面中文硬编码守卫（确保文案严格收拢于 strings.xml，0 违规）
python3 tools/check_strings.py

# 3. 运行 PC 控制台与启动器探活测试（28 项自动化测试）
python3 tools/test_launcher.py

# 4. 执行正式打包构建
./gradlew :app:assembleRelease :app:assembleDebug
```

## 6. 2.0 核心能力实机验证流程

实机功能验收参照 `docs/待实机验证.md` 规范执行：

| 验证项 | 遥控器与实操步骤 | 预期通过表现 |
|---|---|---|
| **OPT-20 学习角点读** | 锁屏状态下，卡片显示时按遥控器 `OK` 键 | 听到点读音频；20s 倒计时暂停，读完恢复；观看限额账本不增加 1 秒。 |
| **OPT-20 掌握度标记** | 遥控器按 `▲`（上键）/ `▼`（下键） | 右上角显示 `✅ 已掌握`（绿标）或 `⭐ 重点学`（金标）；改动自动写回 NAS `state.json`。 |
| **OPT-23 剧集秒开** | 点击包含数十集的目录（如全季动画） | 剧集列表 <50ms 瞬时展开（SWR 本地优先），无网络白屏等待转圈。 |
| **OPT-21 软解回退** | 播放极端非常规编码视频触发硬件解码 4xxx 错误 | 画面不报错崩溃，自动无感切换至软解模式重试成功并继续播放。 |
| **OPT-22/25/26 播放内核** | 播放中按 `OK` 键；按左右键调速；跳过片头片尾 | 单击 OK 仅唤醒控制栏，再次单击切换暂停；调速 0.75x~1.25x 声音不失真；切集无黑屏闪烁。 |
| **OPT-27 海报缩小** | 浏览首页海报列表 | 海报单张宽度 150dp，1080p 屏幕下一屏完整舒适容纳 5~6 张海报。 |
| **OPT-29 扫码配网** | 手机访问 `http://<tv-ip>:8899/pair` 修改并提交 | 电视端日志显示收到 nudge，1 秒内完成热加载重载片单。 |
| **快捷管理** | 首页卡片上长按遥控器 `OK` / `Enter` 键 | 弹出 PIN 输入对话框，验证后可一键「标记今日完成」或「重置进度」。 |

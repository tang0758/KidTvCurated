## RQ-001 · 学习区改进：配图帮助理解 + 古诗「念诗」

- **登记**：2026-11-11，家长口述
- **状态**：待确认
- **原话**：
  1. 「学习区改进，文字和英文可以学习加图片帮助理解。」
  2. 「古诗可以加一个念诗的操作。」

### 现状（登记时）
- 锁屏「等待时间学习角」见 PRD **FR-09**：共 255 张内置卡 —— 57 首唐诗、78 个 A–Z 单词、
  50 幅名画、70 张识字/成语/短句，四类按 `order` 交错轮播，默认 20 秒一张。
- `LearningCard` 已有 `image` 字段，支持 `asset:xxx`（APK 内置图）与 `smb:xxx`（NAS 图片）；
  **目前只有名画卡（ART）用到它**，识字/成语/短句（TEXT）和单词（WORD）、古诗（POEM）都是纯文字。
  名画走 `ArtImages`（采样解码 + 12MB LruCache + 单后台线程），`learning.artFolder` 已能从 NAS 目录
  覆盖名画图 —— 这是「在线拉图」的现成先例。
- 锁屏遥控器按键已被占用（`LockActivity.onKeyDown`）：◀▶ / OK / 回车 / 下一首 → 翻页，
  播放·暂停 / 空格 → 暂停轮播，菜单键 + 数字 PIN → 家长放行，返回键吃掉。
- ROADMAP 第 12 节「明确不做」里有 **「语音交互 / TTS 朗读」**（理由：电视无麦克风、TTS 收益不确定）。
  本需求是**单向播放朗读**，不需要麦克风，与那条决策不完全等价，但涉及 TTS，评估时要一并复核。

### 待确认
| # | 问题 |
|---|---|
| Q1 | 「念诗」的音频从哪来：① 预录 mp3 随资源下发（推荐离线可用）② Android 系统 TTS 朗读 ③ 家长自己录音？电视 Android 9 是否有可用中文 TTS 引擎需实机确认。 |
| Q2 | 触发方式：新加一个遥控器按键（哪个）、长按 OK、还是在卡片上给一个可聚焦的「念诗」按钮？不能和翻页 / 暂停轮播 / PIN 冲突。 |
| Q3 | 「加图片」覆盖哪些卡：只 TEXT + WORD，还是古诗也配意境图？配图从哪来（内置 / NAS / 在线），版权与来源登记（参照 `ART_SOURCES.md`）。 |
| Q4 | 版式：电视 1080p 锁屏右半边，图文同屏后字号是否还够 5 岁半孩子看；图片加载失败时的占位（参考 `Covers.placeholder()`）。 |
| Q5 | 是否放宽 FR-09 的 AC1「断网状态下 255 张卡片全部可显示」；音频/图片拉取失败时是否静默退回纯文字卡（不能让锁屏卡死）。 |
| Q6 | 朗读期间轮播计时是否暂停、音量走哪条音频流、是否会被观看时长账本误记（锁屏本不计时，需守住 `WatchClock` 唯一记账）。 |

## RQ-002 · 学习区资源改为在线拉取，不再编译进 APK

- **登记**：2026-11-11，家长口述
- **状态**：待确认
- **原话**：「学习区是否可以在线拉取。这样不用把资源编译到 apk 中。后台更好也更简单。」

### 现状（登记时）
- 文字类内容写在源码 `data/builtin/{Poems,Words,Arts,Texts}.kt`（合计约 412 行 Kotlin），
  `LearningLibrary` 是**离线**总入口；50 幅名画 jpg 放在 `app/src/main/assets/art/`（约 16 MB）。
  当前 debug APK 约 26 MB，名画图片占了主要头寸。
- 改内置内容 = 改 Kotlin 源码 → 重新打包 → 手动装 APK（见 ROADMAP 14 节发版流程），
  而电视上 v1.5~v1.9 一直没上，改内容的成本明显偏高 —— 这是本需求的痛点。
- 已有两条「在线」通道可复用：
  ① `tv.json` 的 `learning.custom` 可让家长追加自定义卡，`useBuiltin:false` 只用自定义；
  ② `learning.artFolder` + `ArtImages.bindNasArt()` 从 NAS 目录拉图片覆盖名画卡，
     `Smb.readAllIsolated()` / `Smb.withDeadline()` 是片单与图片的既有安全读取方式。
- 设计原则里「装上 APK 锁屏就能看」「断网可用」「只有自家 NAS 片库」是既有前提，
  改在线拉取要正面回答这些前提是否调整（PRD 第 2 节、FR-09 AC1）。

### 待确认
| # | 问题 |
|---|---|
| Q1 | 「在线」指**局域网 NAS**（沿用 SMB，家长在 PC 编辑器里维护）还是公网服务？项目目前不依赖公网，选 NAS 最省事。 |
| Q2 | 数据放哪：扩展 `tv.json` 的 `learning` 段（要同步 `tv.schema.json` + PC 编辑器 + CONFIG 手册），还是独立 `learning.json` / `cards.json`（与 `state.json` 一样独立于片单）？ |
| Q3 | 断了 NAS / 首次启动没缓存时显示什么：保留一份内置卡当兜底（那就仍要编译进 APK，只是变薄）、显示空态提示、还是沿用上次缓存？缓存落盘格式与上限（电视 2.5 GB RAM）。 |
| Q4 | `useBuiltin` / `custom` / `stage` / `order` 这些现有语义是否保留，如何与在线卡合并；老的 `tv.json` 怎么兼容。 |
| Q5 | 图片与音频是否要本地缓存目录（避免每轮轮播重复拉 SMB）、缓存清理、`ArtImages` 的 12MB LRU 是否扩到所有卡类型。 |
| Q6 | 是否需要 PC 后台（极简编辑器 / 控制台 / 桌面助手）加一个「学习卡维护」界面，以及是否纳入 `state.json` 备份范围。 |

### 与 RQ-001 的关系
两条建议**一起评估**：若 RQ-002 的在线资源通道落地，RQ-001 的配图与「念诗」音频正好走同一通道下发，
不必再往 APK 里塞资源；反之若 RQ-002 暂缓，RQ-001 就要先明确图片/音频是内置还是借 `artFolder` 绕行。

## RQ-003 · 视频图标缩小约 30%

- **登记**：2026-11-11 晚，家长口述
- **状态**：待确认（「视频图标」具体指哪个元素还没确认）
- **原话**：「视频图标缩小一些。缩小百分 30 都可以。」

### 现状（登记时）
- **初判落点：首页每个视频的海报卡**（`item_poster.xml`）：整卡 `200dp × 284dp`，
  `marginEnd 18dp` / `marginBottom 8dp`；`ivCover` 铺满卡片 `centerCrop`，底部压 110dp 渐变 +
  14sp 标题；进度角标 12sp。1080p 首屏一行大约 4 张（见工作区 `电视画面预览.png`）。
- **另一个可能**：分区标题旁的小图标 `ivSectionIcon`（`item_section.xml`）是 `22dp × 22dp`、
  `marginEnd 10dp`，来自 OPT-14 的 6 套矢量 `ic_sec_*.xml`，**只有家长在 `tv.json` 配了
  `section.icon` 才显示**；剧集页 `item_episode.xml` 是 76dp 纯文字行，没有图标。
- 焦点表现：`PosterAdapter` 在获得焦点时把整卡 `scaleX/scaleY → 1.10f`，失焦回 `1f`；
  放大所需留白靠 RecyclerView 的 padding（`item_section.xml` 的 `rvRow` 左右 12dp、上下 16dp）。
  **改卡片尺寸要连着复核这个放大与留白**，别让焦点金边/卡片被裁切（项目已有踩坑：
  焦点放大靠 padding，不要 `clipChildren=false`）。
- 缩 30% 若指整体等比：`200 → 140dp`、`284 → 199dp`，一屏可多放 1–2 张；
  标题/角标是否跟着缩要单独定。

### 待确认
| # | 问题 |
|---|---|
| Q1 | 「视频图标」指哪一个：① 首页视频海报卡（初判）② 分区标题的 22dp 小图标 ③ 「继续看」/ 剧集页的其它图？最好指一下屏幕上的位置。 |
| Q2 | 「缩小 30%」是宽高整体 ×0.7，还是只把图上那块图标缩小、卡片外框不变？目标是**一屏多放几个视频**，还是单纯视觉变小、留白更多？ |
| Q3 | 缩小后焦点放大 `1.10f` 与 RecyclerView 留白是否保持；沙发距离下 5 岁半孩子还看不看得清封面和标题。 |
| Q4 | 14sp 标题 / 12sp 进度角标 / 「未解锁」文案是否等比缩小（倾向**保持字号**，只缩图，保证可读）。 |
| Q5 | 所有分区统一缩小，还是只「今天要看的」等特定分区；做成 `tv.json` 里家长可调的尺寸（要同步 schema + PC 编辑器 + CONFIG），还是直接改固定值。 |
| Q6 | 这是 UI 改动，需装包上电视看效果；按约定**周一至周五 09:00–18:00 不做实机安装测试**，排期后用例登记 `待实机验证.md`（含焦点放大不裁切、遥控器翻页、海报墙首屏张数）。 |

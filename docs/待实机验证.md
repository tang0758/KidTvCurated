每轮验收前，先把本清单里「待验证」的条目一次跑完，不要一条一条把电视翻来覆去地折腾。

## 2. 实机测试的固定流程（照抄，别临时发挥）

1. **备份 NAS `curated/tv.json` 原字节**：`pysmb` `retrieveFile` 存成本地文件 + 记 `sha256`。
   同时把 `tv.backup.json`（电视写回时覆盖的那份）和 `state.json`（若存在）也各存一份。
2. **备份电视上的三份 prefs**：`run-as com.family.curated` 读
   `shared_prefs/kid_extras.xml`、`curated_prefs.xml`、`kid_clock.xml` 拉到本地。
3. **只做最小字符串替换**来构造测试配置，不要整份重写 JSON；需要造「写保护」时用
   `resetFileAttributes(..., ATTR_READONLY)`，别改密码、别删文件。
4. 测完**用原字节写回**，回读并逐字节比对 `sha256`；`tv.backup.json` 恢复成正式内容；
   只读属性还原成 `ATTR_NORMAL`；`curated/` 里不留 `probe` 之类的临时文件。
5. 电视 prefs 用 `am force-stop` → `adb push` 到 `/data/local/tmp/` → `run-as ... cp` → 重启 App 还原，
   再 `run-as` 复查没有残留的测试键。
6. 等一个轮询周期（15 秒）确认电视拿回正式片单，再在 [ROADMAP](ROADMAP.md) 第 14 节补一条落地记录，
   并把本清单里对应的行改成 `通过` / `失败`（失败要写清现象与日志行）。

可复用脚本：`.workbuddy/tmp/wave1_nas.py`、`.workbuddy/tmp/wave2_nas.py`（备份 / 测试配置 / 还原 / 只读属性）。

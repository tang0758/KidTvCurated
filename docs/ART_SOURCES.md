# 内置名画图片来源

全部来自 Wikimedia Commons，作者逝世均已超过著作权保护期，属公共领域作品。
图片由 `tools/fetch_art.py` 通过 Commons API 下载 800px 缩略图，
编译进 APK 的 `assets/art/`，电视不联网也能显示。

共 50 幅。含中国画 5 幅、日本浮世绘 2 幅，题材以风景、动物、儿童与日常生活为主。
